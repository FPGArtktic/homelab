Homelab

Host debian-srv (192.168.101.253), rootless Podman, Quadlet + systemd user units. Ustawienia źródłowe są w repozytorium homelab.

Gdzie są rzeczy

Sekrety (nie w git)~/.config/homelab/homelab.env, portainer_admin_password
Dane (pliki, ArchiveBox, bazy)~/homelab/data/
Dane named volumespodman volume ls (gitlab_*, forgejo_data, grafana_data, prometheus_data, mikrodash_data, ...)

Najczęstsze polecenia

systemctl --user list-units 'homelab*' nginx.service gitlab.service   # stan
systemctl --user --failed                                             # co padło
systemctl --user restart gitlab                                       # jedna usługa
journalctl --user -u forgejo -f                                       # logi
podman ps                                                             # kontenery
~/homelab/scripts/install.sh                                          # wdrożenie zmian z repo

Strona jest statyczna i pisana ręcznie. Po zmianie portów lub usług zaktualizuj ją w repo (site/index.html).
